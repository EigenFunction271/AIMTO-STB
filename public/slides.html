THE DESIGN_AI is one helper

THE BOUNDARY_Flexibility versus certainty

AI

  3. 03Control promises
Same order. Same total. Every time.
AI for language · rules for certainty14
Use AI where language is messy. Use fixed rules where the answer must be guaranteed. A customer message must never be able to change prices or promises.
